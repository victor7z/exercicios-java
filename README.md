Exercícios Java ☕💻

Este repositório reúne exercícios e desafios práticos desenvolvidos durante minha jornada de aprendizado em Java, com o objetivo de fortalecer meus conhecimentos, aprimorar meu raciocínio lógico e desenvolver autonomia na resolução de problemas.

Conhecimentos praticados

Fundamentos e sintaxe da linguagem Java

Variáveis, tipos de dados e operadores

Estruturas condicionais (if/else e switch)

Estruturas de repetição (for, while e do-while)

Arrays e arrays multidimensionais

Programação Orientada a Objetos (POO)

Classes, objetos, atributos e métodos

Métodos com parâmetros e retornos

Referências de objetos

Validação de dados e regras de negócio

Objetivo

Aplicar os conceitos estudados em exercícios próprios, desenvolvendo soluções progressivamente mais completas e preparando minha base técnica para projetos reais e oportunidades de estágio em desenvolvimento de software.

Tecnologia: Java
Ambiente de desenvolvimento: IntelliJ IDEA
Status: Em constante desenvolvimento e aprendizado.
