# Exercícios Java ☕💻

Exercícios e desafios práticos que faço durante meus estudos de Java, para fortalecer minha lógica de programação, treinar orientação a objetos e ganhar autonomia na resolução de problemas.

## 📚 O que já pratiquei

- Fundamentos e sintaxe da linguagem Java
- Variáveis, tipos de dados e operadores
- Estruturas condicionais (`if/else` e `switch`)
- Estruturas de repetição (`for`, `while` e `do-while`)
- Arrays e arrays multidimensionais
- Classes, objetos, atributos e métodos
- Métodos com parâmetros e com retorno
- Referências de objetos
- Validação de dados e regras de negócio

## 🔄 Estudando agora

- Encapsulamento
- Construtores
- Sobrecarga
- Membros estáticos

## 🧭 Próximos passos

- Herança e polimorfismo
- Classes abstratas e interfaces
- Tratamento de exceções
- Collections Framework
- Manipulação de arquivos

## 🛠️ Tecnologias

Java · IntelliJ IDEA · Git e GitHub

## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/victor7z/exercicios-java.git
   ```
2. Abra a pasta no IntelliJ IDEA.
3. Dentro de `src`, abra a classe que quiser e execute o método `main`.

## 📌 Status

Em constante desenvolvimento. Os exercícios são de estudo e podem receber correções e melhorias conforme eu aprendo.
